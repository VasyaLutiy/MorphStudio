# Morph Studio — упаковка автономного Морфа для коллег (набросок 07.10.2026, обновлён 08.10)

> Это набросок-идея, вход для интервью Начала. План фаз и запись Contour напишет архитектор
> (`morph-architect`); при передаче набросок переедет в `docs/SKETCH.md`.

## 1. Что продаём одной фразой

Коллега открывает веб-страницу, отдаёт три вещи: свой токен Claude, «/start» в Телеграме и идею
проекта. Получает на ноуте **PM-оркестратора** (Claude Code + скилл `morph-pm`). Тот проводит
интервью, пишет запись Contour и план фаз, согласует их с коллегой и отдаёт **автономной сессии на
Hetzner**. Сессия строит каркас проекта колодами Морфа, а PM следит, отчитывается и останавливает.

Это ровно наш с тобой режим, только разобранный двигатель собран в корпус.

## 2. Пять ограничений скилла `morph-pm` (зашиты в текст скилла, а не в доброжелательность)

1. **Только с нуля.** Чужой или существующий репозиторий скилл отклоняет: «онбординг чужого
   проекта не мой критерий» (наш вывод 27.09 о границе primer).
2. **Код не пишу.** PM пишет только данные: интервью, `contour.yaml`, `morph-map.json`, спеки
   фаз, фикстуры. Код пишет Морф. Правка кода руками — нарушение, как у нас в CLAUDE.md.
3. **Начало — главная фаза.** Первое сообщение объясняет, что час разговора сейчас экономит дни
   потом. Интервью идёт по шаблону: цель, пользователи, Data Objects, сценарии, чего НЕ делаем,
   стек.
4. **Продакшна не будет.** PM сразу предупреждает, что результат — базовый каркас по записи
   Contour: слои, типы, функции с примерами, тесты. Без деплоя, без полировки UI, без «под ключ».
5. **План фиксируется и апрувится.** `PLAN.md` с фазами, бюджетом и smoke-стопами коммитится,
   его хэш уходит в ТГ, коллега отвечает «approve». Без апрува автоген не стартует. Любая правка
   плана — новый апрув.

Кроме того, в скилл переезжают мои уроки: немногословный PM, статус в 2–4 строки с числами, стоп
по красной карте после починки, долги, потолок $ на фазу, smoke-стопы, «сводка на одном экране».

## 3. Путь пользователя (фазы продукта)

| # | Этап | Где | Кто | Выход |
|---|------|-----|-----|-------|
| U0 | Регистрация | веб | коллега | аккаунт, инвайт-код от тебя |
| U1 | Секреты | веб | коллега | Claude-токен (`claude setup-token` на ноуте → вставить), ТГ (кнопка `t.me/MorphStudioBot?start=<nonce>`, без своего бота), ключ OpenRouter (свой или твой с лимитом) |
| U2 | Провижининг | VPS | бэкенд | изолированный env: контейнер или юзер, репо проекта из шаблона, скиллы, `.env`, tmux |
| U3 | Проверка env | VPS + ТГ | бэкенд, затем PM | чек-лист: `claude -p ping`, тестовое сообщение в ТГ, `morph run` на stub, один живой вызов за цент. Всё ✅ — открывается U4 |

| U5 | **Начало** | ноут | PM ↔ коллега | интервью → `contour.yaml`, `PLAN.md` |
| U6 | Апрув плана | ноут + ТГ | коллега | коммит плана + 👍 в ТГ |
| U7 | Автоген | VPS | сессия | фазы по AUTONOMY, вехи в ТГ |
| U8 | Наблюдение | ноут | PM | smoke-стопы, отчёты, возобновление, долги → коллеге |

## 4. Архитектура (лёгкая)

```
ноут коллеги                          Hetzner VPS
┌───────────────────┐   HTTPS+токен   ┌──────────────────────────────────────┐
│ Claude Code       │ ─── MCP ──────▶ │ studio-api (Node/TS, SQLite)         │
│  plugin morph-    │                 │  ├ onboarding (секреты, шифрованно)  │
│  studio:          │                 │  ├ provisioner (контейнер на юзера)  │
│  - skill morph-pm │                 │  ├ control: status/screen/order/     │
│  - agents         │                 │  │  resume/usage/events (long-poll)  │
│  - seed-память    │                 │  └ tg-router (один бот, chat по nonce)│
└───────────────────┘                 │ studio-web (серверные HTML + htmx)   │
браузер ─────── веб-мастер U0–U4 ───▶ │ env-<user>/ : tmux claude + morph V2 │
                                      └──────────────────────────────────────┘
```

Ключевое решение: **PM ходит на VPS через удалённый MCP**, а не через ssh и tmux, как я сейчас.
Инструменты `status`, `screen`, `order`, `resume`, `usage`, `wait_event` заменяют мой
`vps-watch.sh`, ручные `send-keys` и ssh-ключ, которого у коллег быть не должно.

## 5. Как это строит Морф (dogfooding второго уровня)

Новое репо `morph-studio` с нуля — **первый клиент собственного процесса**. Я играю `morph-pm`
для тебя: интервью → Contour → план → автоген на VPS с V2 на ds.

Руками (данные):
- **D1** — скиллы `morph-pm` и `morph-architect` — черновики готовы 08.10 (`.claude/skills/`), у оператора на ревью;
- **D2** — шаблон проекта — делает Морф в MorphV2 P18 (`morph init --name --language` из `templates/`,
  common + typescript/go/python, без следов MorphV2);
- **D3** — манифест плагина и seed-память;
- **D4** — Dockerfile env-образа (claude, node, morph V2, скиллы).

Морфом (код TypeScript, профиль typescript V2), Component ≤ 30 КБ:

| Фаза | Component | Суть | Приёмка |
|---|---|---|---|
| S1 | store | users, envs, secrets (libsodium sealed), машина состояний U0–U8 | vitest |
| S2 | intake | проверка Claude-токена (sandbox `claude -p`), ТГ nonce→chat_id, OpenRouter `/key` | vitest + замоканный fetch |
| S3 | provisioner | создание, старт, стоп env; идемпотентно; dry-run для тестов | vitest на dry-run + smoke на VPS |
| S4 | control | status/screen/order/resume/usage/events; авторизация токеном env | vitest |
| S5 | mcp | удалённый MCP-сервер поверх control | vitest + живой `claude mcp add` smoke |
| S6 | envcheck | чек-лист U3, отчёт в ТГ | vitest + smoke |
| S7 | web | мастер U0–U4 (серверный HTML + htmx, без SPA) | vitest на хэндлерах + один playwright smoke |
| S8 | tg-router | один бот, маршрутизация вех по env | vitest |

Это примерно 8 фаз по 8–12 карт, исполнитель ≈ $1–2. Основная цена — Claude-часы оркестратора.

## 7. Риски и вопросы к тебе — оператор 08.10: закрыты (ответы → `docs/DECISIONS.md`)

1. **Изоляция.** Несколько Claude-сессий в bypass-permissions на одной машине — только
   контейнер на пользователя (rootless docker или systemd-nspawn), без общего `$HOME`.
   Ёмкость одной VPS — 3–5 одновременных env?
2. **Подписка и лимит.** У нас ≈ $267 за 06–07.10 и около 45% пятичасового окна при двух
   сессиях. На Pro коллега упрётся в лимит за час. Требовать Max? — **оператор 07.10: узнаем на пилоте с коллегами**, мерить расход окна на env. Правила Anthropic о запуске
   подписки на чужом сервере — проверить до запуска.
3. **OpenRouter.** Ключ коллеги или твой с лимитом на env? Твой проще в онбординге, но платишь ты.
4. **Где живёт репо проекта.** Локальный git на VPS, клон на ноут через control API, или GitHub
   коллеги (fine-grained PAT)?
5. **Ты как оператор.** Видишь все env (админка) или нет?
6. **Имя.** Morph Studio — рабочее.
